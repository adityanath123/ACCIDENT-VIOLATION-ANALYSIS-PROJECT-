# ACCIDENT & VIOLATION-ANALYSIS-PROJECT- (Power BI)

## 📌 Project Overview
This project analyzes traffic accidents & violations(Based on the top 5 cities of india) data using **Power BI**.
The dashboard helps identify violation and accident trends.

## 🛠 Tools Used
- Power BI
- Power Query
- DAX
- CSV Dataset

## 📊 Key Insights (KPI CARDS) 
- Total Accidents
- Total fatalities
- Total violations
- Total fines collected
- Repet offenders
